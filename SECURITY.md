# Security

Please report vulnerabilities and privacy leaks privately. Examples of the second kind: metadata such as EXIF or GPS surviving into an exported image, or image bytes leaving the browser.

Use GitHub's private vulnerability reporting: open the [Security tab](https://github.com/abijith-suresh/reshrimp/security) of the repository and choose "Report a vulnerability".

Include the steps to reproduce, the browser and version, and, if you can, a test image that does not contain anything private. Please do not open a public issue for these reports.

Only the latest release on https://reshrimp.vercel.app is supported.
